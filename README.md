# WP Cookie Notice

Легковесный плагин WordPress для отображения уведомления об использовании файлов cookie и соответствия требованиям GDPR / закона о персональных данных.

Плагин разработан с акцентом на производительность и чистую архитектуру: без jQuery и внешних зависимостей на фронтенде (чистый Vanilla JS весом ~1.2 KB), с управлением через нативный **WordPress Settings API**.

## Возможности

- **Настройки через админку:** отдельная страница в меню **Настройки → Cookie Notice**.
- **Кастомизация текста и ссылок:** редактирование текста уведомления, кнопки закрытия и ссылки на Политику конфиденциальности (по умолчанию подтягивается системный URL из WordPress).
- **Цветовая палитра:** настройка цвета фона, текста и кнопки через встроенный `wp-color-picker`.
- **Выбор позиции:** фиксация баннера внизу (`bottom`) или вверху экрана (`top`).
- **Срок действия согласия:** настраиваемый срок жизни cookie (по умолчанию 30 дней) с синхронизацией в `localStorage`.
- **Без сторонних библиотек:** нативный Vanilla JS, не блокирует рендеринг страницы и не влияет на метрики Core Web Vitals (LCP, FID/INP, CLS).
- **Безопасность:** валидация и санитизация всех полей (`sanitize_hex_color`, `esc_url_raw`, `sanitize_textarea_field`), проверка nonce и прав доступа пользователя (`manage_options`).

## Хуки и фильтры для разработчиков

Плагин предоставляет хуки для кастомизации поведения из темы или других плагинов:

### 1. Фильтр отображения баннера
Позволяет отключить показ уведомления на определенных страницах (например, на странице самой политики конфиденциальности):

```php
add_filter( 'wp_cookie_notice_should_render', function( $should_render ) {
    if ( is_privacy_policy() ) {
        return false;
    }
    return $should_render;
});
```

### 2. Экшен после баннера
Позволяет добавить кастомную разметку или скрипты аналитики:

```php
add_action( 'wp_cookie_notice_after_banner', function() {
    // Кастомный вывод
});
```

## Установка

1. Склонируйте репозиторий в каталог плагинов вашего WordPress-сайта:
   ```bash
   cd wp-content/plugins/
   git clone https://github.com/Lelyaler/wp-cookie-notice.git
   ```
   *Или скачайте архив репозитория и загрузите через **Плагины → Добавить новый → Загрузить плагин**.*

2. Активируйте плагин в разделе **Плагины** админ-панели WordPress.
3. Перейдите в **Настройки → Cookie Notice** для настройки текстов и цветов.
